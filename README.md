# StegoShare

StegoShare is a terminal-based reversible audio steganography application that
combines interpolation-based embedding with Shamir Secret Sharing. The current
project version is consolidated into a single executable source file,
`main.py`.

The program supports two execution modes:

- interactive menu mode for local manual use,
- non-interactive command-line mode for scripted and reproducible runs.

## 1. Features

- Binary payload embedding into cover audio using a configurable `(n, k)` share scheme.
- Multiple stego-audio share generation: `stegoaudio0.wav`, `stegoaudio1.wav`, and so on.
- Payload and reconstructed cover-audio extraction from at least `k` stego-audio shares.
- Original vs extracted payload comparison.
- Original cover audio vs extracted audio comparison.
- Stego-audio quality evaluation using `MSE`, `SNR`, and `PSNR`.
- Running time and peak memory usage reporting for embedding experiments.
- Steganalysis:
  - SVM-based Machine Learning detector benchmark,
  - entropy and Normalized Correlation (NC) analysis for a single audio pair,
  - batch entropy and NC analysis with Excel report export.

## 2. Project Structure

Current source files:

- `main.py`: main application file containing all menus, algorithms, workflows, and CLI commands.
- `README.md`: project documentation.
- `LICENSE`: project license.

Current folders:

- `DATASET/Audio`: cover audio files, currently `data1_mono.wav` through `data15_mono.wav`.
- `DATASET/Payload`: payload files, currently `payload1.txt` through `payload11.txt`.
- `results`: generated output directory.

Generated output folders:

- `results/STEGOAUDIO`: stego-audio shares generated by embedding.
- `results/EXTRACTED`: payload and audio generated by extraction.
- `results/CLONING`: cloned cover audio generated during quality evaluation.
- `results/STEGANALYSIS`: Excel reports generated by batch steganalysis.

Directory overview:

```text
.
|-- main.py
|-- README.md
|-- LICENSE
|-- DATASET/
|   |-- Audio/
|   `-- Payload/
`-- results/
    |-- STEGOAUDIO/
    |-- EXTRACTED/
    |-- CLONING/
    `-- STEGANALYSIS/
```

The `results` subfolders are created automatically when the related workflow is
run.

## 3. Requirements

- Python 3.9 or newer. Python 3.10 is recommended.
- Windows, Linux, or macOS.

Python packages:

- `numpy`
- `scipy`
- `sympy`
- `scikit-learn`
- `openpyxl`

## 4. Installation

From the project root directory:

```bash
python3 -m venv .venv
```

Activate the virtual environment.

Windows PowerShell:

```bash
.venv\Scripts\Activate.ps1
```

Windows CMD:

```bash
.venv\Scripts\activate.bat
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
python3 -m pip install --upgrade pip
python3 -m pip install numpy scipy sympy scikit-learn openpyxl
```

On Windows, `py -3` can be used instead of `python3`:

```bash
py -3 -m pip install numpy scipy sympy scikit-learn openpyxl
```

## 5. How to Run

### Interactive Mode

Run the main menu:

```bash
python3 main.py
```

On Windows:

```bash
py -3 main.py
```

Main menu:

```text
1. Embedding
2. Extracting
3. Evaluation
4. Exit
```

Evaluation submenu:

```text
1. Compare payload and audio
2. Check audio quality
3. Detector ML
4. NC and entropy analysis (single)
5. NC and entropy analysis (batch + excel)
```

### Non-Interactive Mode

For scripted or reproducible runs, pass a command and its arguments to
`main.py`. When arguments are provided, the program uses `argparse` and skips
all interactive prompts.

Show all available commands:

```bash
python3 main.py --help
```

Command overview:

```bash
python3 main.py embedding --audio X --payload Y --shares N --min-shares K
python3 main.py extracting --audio X --payload Y --shares N --min-shares K
python3 main.py extracting --audio X --payload Y --shares N --min-shares K --share-indices 0 1 2
python3 main.py compare --audio X --payload Y
python3 main.py quality --audio X --payload Y --share S
python3 main.py detector --audio X
python3 main.py nc-single --audio X --payload Y --share S
python3 main.py nc-batch --total-audio 15 --total-payload 11
```

Use `--help` on a subcommand to inspect its arguments:

```bash
python3 main.py embedding --help
python3 main.py extracting --help
python3 main.py nc-batch --help
```

## 6. Usage Flow

### A. Embedding

Interactive menu:

```text
1. Embedding
```

Non-interactive command:

```bash
python3 main.py embedding --audio 1 --payload 1 --shares 5 --min-shares 3
```

Inputs:

- Audio number `X`.
- Payload number `Y`.
- Total and minimum shares in `(n k)` format.

Input files:

```text
DATASET/Audio/dataX_mono.wav
DATASET/Payload/payloadY.txt
```

Example interactive input:

```text
Enter audio number from DATASET: 1
Enter payload number from DATASET: 1
Enter total and minimum shares (n k): 5 3
```

Output:

```text
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudio0.wav
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudio1.wav
...
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudio(n-1).wav
```

The program also prints the output folder, peak memory usage, and embedding
runtime.

Example performance output:

```text
Peak memory: 12.34 MB
Embedding runtime: 1.234567
```

### B. Extracting

Interactive menu:

```text
2. Extracting
```

Non-interactive command with random share selection:

```bash
python3 main.py extracting --audio 1 --payload 1 --shares 5 --min-shares 3
```

Non-interactive command with fixed share indices:

```bash
python3 main.py extracting --audio 1 --payload 1 --shares 5 --min-shares 3 --share-indices 0 1 2
```

Inputs:

- Audio number `X`.
- Payload number `Y`.
- Total and minimum shares in `(n k)` format.

Expected input files:

```text
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudio0.wav
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudio1.wav
...
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudio(n-1).wav
```

Output:

```text
results/EXTRACTED/stego_audioX_payloadY/payload.txt
results/EXTRACTED/stego_audioX_payloadY/audio.wav
```

In interactive extraction, the program randomly selects `k` shares from the
available `n` shares. For reproducible non-interactive extraction, use
`--share-indices`.

### C. Compare Payload and Audio

Interactive menu:

```text
3. Evaluation
1. Compare payload and audio
```

Non-interactive command:

```bash
python3 main.py compare --audio 1 --payload 1
```

Compared files:

- Original payload: `DATASET/Payload/payloadY.txt`
- Extracted payload: `results/EXTRACTED/stego_audioX_payloadY/payload.txt`
- Original audio: `DATASET/Audio/dataX_mono.wav`
- Extracted audio: `results/EXTRACTED/stego_audioX_payloadY/audio.wav`

The output reports whether the payload and audio are `Exact` or `Different`.

### D. Quality Evaluation

Interactive menu:

```text
3. Evaluation
2. Check audio quality
```

Non-interactive command:

```bash
python3 main.py quality --audio 1 --payload 1 --share 0
```

Inputs:

- Audio number `X`.
- Payload number `Y`.
- Stego-audio share number, default `0`.

Input files:

```text
DATASET/Audio/dataX_mono.wav
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudioS.wav
```

Output metrics:

- `MSE`
- `SNR`
- `PSNR`

The program also creates a cloned cover audio file:

```text
results/CLONING/data_clone_audioX.wav
```

### E. Detector ML

Interactive menu:

```text
3. Evaluation
3. Detector ML
```

Non-interactive command:

```bash
python3 main.py detector --audio 1
```

The detector uses an SVM model with statistical, spectral, difference, and
histogram-moment features extracted from audio segments. Cover data is compared
against all available stego-audio files in `results/STEGOAUDIO`.

Main output:

- number of cover and stego segments,
- confusion matrix,
- accuracy,
- precision,
- recall,
- F1-score,
- AUC-ROC,
- cross-validation accuracy.

Run embedding first so `results/STEGOAUDIO` contains `stegoaudio*.wav` files.

### F. Single NC and Entropy Analysis

Interactive menu:

```text
3. Evaluation
4. NC and entropy analysis (single)
```

Non-interactive command:

```bash
python3 main.py nc-single --audio 1 --payload 1 --share 0
```

Inputs:

- Audio number `X`.
- Payload number `Y`.
- Stego-audio share number, default `0`.

Input stego file:

```text
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudioS.wav
```

Output:

- cover entropy,
- stego entropy,
- entropy difference,
- entropy change percentage,
- Normalized Correlation (NC).

### G. Batch NC and Entropy Analysis + Excel

Interactive menu:

```text
3. Evaluation
5. NC and entropy analysis (batch + excel)
```

Non-interactive command with automatic share detection:

```bash
python3 main.py nc-batch --total-audio 15 --total-payload 11
```

Non-interactive command with fixed share count:

```bash
python3 main.py nc-batch --total-audio 15 --total-payload 11 --shares 5
```

Inputs:

- total audio files, default `15`,
- total payload files, default `11`,
- total shares `n`, or leave blank for auto-detection.

The program scans combinations such as:

```text
DATASET/Audio/dataX_mono.wav
results/STEGOAUDIO/stego_audioX_payloadY/stegoaudioS.wav
```

Default Excel output:

```text
results/STEGANALYSIS/steganalysis_auto_shares.xlsx
```

If total shares is provided, the output filename follows that value:

```text
results/STEGANALYSIS/steganalysis_5_shares.xlsx
```

Generated Excel sheets:

- `Share Details`
- `Summary (Avg)`
- `Summary (Best)`
- `Summary (Worst)`
- pivot sheets per metric and share
- `Metric Notes`

## 7. Running Time and Memory Usage

StegoShare reports performance metrics to help compare experiments across
different audio files, payload sizes, and `(n, k)` share configurations.

### Running Time

Running time measures elapsed execution time in seconds.

- Embedding: printed as `Embedding runtime`.
- ZIP-based extraction helper: returned as `runtime` from
  `run_single_extraction()` when used programmatically.

Example:

```text
Embedding runtime: 1.234567
```

### Memory Usage

Memory usage is reported as peak memory in megabytes (`MB`) during embedding.
The value is measured with Python `tracemalloc`, so it represents peak traced
Python memory allocations during the embedding process.

Example:

```text
Peak memory: 12.34 MB
```

For consistent measurements, run experiments on the same machine, close
unnecessary applications, and use the same dataset and `(n, k)` configuration
when comparing results.

## 8. Dataset Format

Cover audio naming format:

```text
DATASET/Audio/dataX_mono.wav
```

Payload naming format:

```text
DATASET/Payload/payloadY.txt
```

Examples:

```text
DATASET/Audio/data1_mono.wav
DATASET/Payload/payload1.txt
```

Payload files are read as binary data stored in text files. For reproducible
experiments, keep the dataset format and naming convention unchanged.

## 9. Experiment Notes

- Use the same `(audio_no, payload_no, n, k)` configuration for embedding,
  extraction, comparison, quality evaluation, and steganalysis.
- `n` or `--shares` is the total number of shares generated during embedding.
- `k` or `--min-shares` is the minimum number of shares required for reconstruction.
- Interactive extraction randomly selects `k` shares from all available shares.
- For reproducible non-interactive extraction, use `--share-indices`.
- Batch steganalysis only processes audio-payload combinations whose stego-audio
  files already exist.
- Embedding outputs, extraction outputs, cloned audio, and Excel reports can be
  regenerated by rerunning the workflow.

## 10. Troubleshooting

### `Audio file not found`

Make sure the cover audio file exists and follows this naming format:

```text
DATASET/Audio/dataX_mono.wav
```

### `Payload file not found`

Make sure the payload file exists and follows this naming format:

```text
DATASET/Payload/payloadY.txt
```

### `Incomplete stego-audio file`

The number of stego-audio files must match the `n` or `--shares` value used
during extraction.

Example for `n = 5`:

```text
stegoaudio0.wav
stegoaudio1.wav
stegoaudio2.wav
stegoaudio3.wav
stegoaudio4.wav
```

### `No stego files found`

Run embedding first. Detector ML and batch steganalysis require stego-audio
files inside:

```text
results/STEGOAUDIO/stego_audioX_payloadY/
```

### Compare result is different

Make sure the same `audio_no`, `payload_no`, `n`, and `k` configuration is used
for embedding and extraction.

### Import or dependency error

Reactivate the virtual environment and reinstall dependencies:

```bash
python3 -m pip install numpy scipy sympy scikit-learn openpyxl
```

On Windows:

```bash
py -3 -m pip install numpy scipy sympy scikit-learn openpyxl
```
