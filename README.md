# StegoShare

StegoShare is a reversible audio steganography project that combines
interpolation-based embedding with Shamir Secret Sharing. The project provides a
terminal-based workflow for embedding payloads into audio, extracting payloads
from stego-audio shares, verifying extraction results, evaluating audio quality,
and running steganalysis.

## 1. Features

- Binary payload embedding into cover audio using a configurable `(n, k)` share scheme.
- Multiple stego-audio share generation: `stegoaudio0.wav`, `stegoaudio1.wav`, and so on.
- Payload and cover-audio extraction from at least `k` stego-audio shares.
- Original vs extracted payload comparison.
- Original cover audio vs extracted audio comparison.
- Stego-audio quality evaluation using `MSE`, `SNR`, and `PSNR`.
- Steganalysis:
  - machine learning detector benchmark using SVM,
  - entropy and normalized correlation (NC) analysis for a single audio pair,
  - batch entropy and NC analysis with Excel report export.

## 2. Project Structure

Main files:

- `main.py`: main menu launcher.
- `embedding.py`: embeds a payload into cover audio.
- `extracting.py`: extracts payload and audio from stego-audio shares.
- `single_compare.py`: compares original payload/audio with extracted results.
- `quality_evaluation.py`: evaluates stego-audio quality.
- `steganalysis.py`: ML detector, entropy analysis, NC analysis, and Excel export.
- `methods.py`: core utilities for interpolation, secret sharing, embedding, and extraction.

Main folders:

- `DATASET/Audio`: cover audio files, for example `data1_mono.wav` to `data15_mono.wav`.
- `DATASET/Payload`: payload text/binary files, for example `payload1.txt` to `payload11.txt`.
- `STEGOAUDIO`: generated stego-audio outputs.
- `EXTRACTED`: extracted payload and audio outputs.
- `CLONING`: temporary cloned cover audio for quality evaluation.
- `steganalysis_results`: Excel reports generated by batch steganalysis.

## 4. Installation

From the project root directory:

```bash
py -m venv .venv
```

Activate the virtual environment.

Windows PowerShell:

```bash
.venv\Scripts\Activate.ps1
```

Windows CMD:

```bash
.venv\Scripts\activate.bat
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
py -m pip install --upgrade pip
py -m pip install numpy scipy sympy scikit-learn openpyxl
```

If `py` is not available on Linux/macOS, use:

```bash
python -m pip install numpy scipy sympy scikit-learn openpyxl
```

## 6. Usage Flow

### A. Embedding

Module: `embedding.py`

Run from the main menu by selecting `1`, or run directly:

```bash
py embedding.py
```

Inputs:

- Audio number `X`.
- Payload number `Y`.
- Total and minimum shares in `(n k)` format.

Input files:

- `DATASET/Audio/dataX_mono.wav`
- `DATASET/Payload/payloadY.txt`

Example input:

```text
Enter audio number from DATASET: 1
Enter payload number from DATASET: 1
Enter total and minimum shares (n k): 5 3
```

Output:

```text
STEGOAUDIO/stego_audioX_payloadY/stegoaudio0.wav
STEGOAUDIO/stego_audioX_payloadY/stegoaudio1.wav
...
STEGOAUDIO/stego_audioX_payloadY/stegoaudio(n-1).wav
```

The program also prints the output folder, peak memory usage, and embedding
runtime.

### B. Extracting

Module: `extracting.py`

Run from the main menu by selecting `2`, or run directly:

```bash
py extracting.py
```

Inputs:

- Audio number `X`.
- Payload number `Y`.
- Total and minimum shares in `(n k)` format.

Expected input files:

```text
STEGOAUDIO/stego_audioX_payloadY/stegoaudio0.wav
STEGOAUDIO/stego_audioX_payloadY/stegoaudio1.wav
...
STEGOAUDIO/stego_audioX_payloadY/stegoaudio(n-1).wav
```

Example input:

```text
Enter audio number [X]: 1
Enter payload number [Y]: 1
Enter total and minimum shares (n k): 5 3
```

Output:

```text
EXTRACTED/stego_audioX_payloadY/payload.txt
EXTRACTED/stego_audioX_payloadY/audio.wav
```

During CLI extraction, the program randomly selects `k` shares from the available
`n` shares.

### C. Compare Payload and Audio

Module: `single_compare.py`

Run from the main menu:

```text
3. Evaluation
1. Compare payload and audio
```

Or run directly:

```bash
py single_compare.py
```

Compared files:

- Original payload: `DATASET/Payload/payloadY.txt`
- Extracted payload: `EXTRACTED/stego_audioX_payloadY/payload.txt`
- Original audio: `DATASET/Audio/dataX_mono.wav`
- Extracted audio: `EXTRACTED/stego_audioX_payloadY/audio.wav`

The output reports whether the payload and audio are `Exact` or `Different`.

### D. Quality Evaluation

Module: `quality_evaluation.py`

Run from the main menu:

```text
3. Evaluation
2. Check audio quality
```

Or run directly:

```bash
py quality_evaluation.py
```

Inputs:

- Audio number `X`.
- Payload number `Y`.
- Stego-audio share number, default `0`.

Input files:

- Cover audio: `DATASET/Audio/dataX_mono.wav`
- Stego audio: `STEGOAUDIO/stego_audioX_payloadY/stegoaudioS.wav`

Output metrics:

- `MSE`
- `SNR`
- `PSNR`

The program also creates a cloned cover audio file:

```text
CLONING/data_clone_audioX.wav
```

### E. Detector ML

Module: `steganalysis.py`

Run from the main menu:

```text
3. Evaluation
3. Detector ML
```

Or select mode `1` in `steganalysis.py`:

```bash
py steganalysis.py
```

The detector uses an SVM model with statistical, spectral, difference, and
histogram-moment features extracted from audio segments. Cover data is compared
against all available stego-audio files in `STEGOAUDIO`.

Main output:

- number of cover and stego segments,
- confusion matrix,
- accuracy,
- precision,
- recall,
- F1-score,
- AUC-ROC,
- cross-validation accuracy.

Run embedding first so the `STEGOAUDIO` folder contains `stegoaudio*.wav` files.

### F. Single NC and Entropy Analysis

Module: `steganalysis.py`

Run from the main menu:

```text
3. Evaluation
4. NC and entropy analysis (single)
```

Or select mode `2` in `steganalysis.py`.

Inputs:

- Audio number `X`.
- Payload number `Y`.
- Stego-audio share number, default `0`.

Output:

- cover entropy,
- stego entropy,
- entropy difference,
- entropy change percentage,
- normalized correlation (NC).

### G. Batch NC and Entropy Analysis + Excel

Module: `steganalysis.py`

Run from the main menu:

```text
3. Evaluation
5. NC and entropy analysis (batch + excel)
```

Or select mode `3` in `steganalysis.py`.

Inputs:

- total audio files, default `15`,
- total payload files, default `11`,
- total shares `n`, or leave blank for auto-detection.

The program scans combinations such as:

```text
DATASET/Audio/dataX_mono.wav
STEGOAUDIO/stego_audioX_payloadY/stegoaudioS.wav
```

Default Excel output:

```text
steganalysis_results/steganalysis_auto_shares.xlsx
```

If total shares is provided, the output filename follows that value, for example:

```text
steganalysis_results/steganalysis_5_shares.xlsx
```

Generated Excel sheets:

- `Share Details`
- `Summary (Avg)`
- `Summary (Best)`
- `Summary (Worst)`
- pivot sheets per metric and share
- `Metric Notes`

## 8. Dataset Format

Cover audio naming format:

```text
DATASET/Audio/dataX_mono.wav
```

Payload naming format:

```text
DATASET/Payload/payloadY.txt
```

Example:

```text
DATASET/Audio/data1_mono.wav
DATASET/Payload/payload1.txt
```

Payload files are read as binary data stored in text files. For reproducible
experiments, keep the dataset format and naming convention unchanged.

## 9. Common Issues

### `Audio file not found`

Make sure the cover audio file exists and follows this naming format:

```text
DATASET/Audio/dataX_mono.wav
```

### `Payload file not found`

Make sure the payload file exists and follows this naming format:

```text
DATASET/Payload/payloadY.txt
```

### `Incomplete stego-audio file`

The number of stego-audio files must match the `n` value entered during
extraction.

Example for `n = 5`:

```text
stegoaudio0.wav
stegoaudio1.wav
stegoaudio2.wav
stegoaudio3.wav
stegoaudio4.wav
```

### `No stego files found`

Run embedding first. The ML detector and batch steganalysis require stego-audio
files inside:

```text
STEGOAUDIO/stego_audioX_payloadY/
```

### Compare result is different

Make sure the same `audio_no`, `payload_no`, `n`, and `k` configuration is used
for embedding and extraction.

### Import/module error

Reactivate the virtual environment and reinstall dependencies:

```bash
py -m pip install numpy scipy sympy scikit-learn openpyxl
```

## 10. Experiment Notes

- Use the same `(audio_no, payload_no, n, k)` configuration for embedding,
  extracting, comparison, quality evaluation, and steganalysis.
- `k` is the minimum number of shares required for reconstruction.
- `n` is the total number of shares generated during embedding.
- CLI extraction randomly selects `k` shares from all available shares.
- Batch steganalysis only processes audio-payload combinations whose stego files
  already exist.
- Embedding outputs, extraction outputs, cloned audio, and Excel reports can be
  regenerated by rerunning the workflow.
